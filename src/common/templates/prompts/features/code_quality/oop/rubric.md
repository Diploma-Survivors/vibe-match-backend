# Code Quality Rubric (OOP)

Score 0-100.

- **Encapsulation (40 pts)**:
  - Private/Protected used correctly.
  - Getters/Setters where appropriate.
- **Design (40 pts)**:
  - Single Responsibility Principle.
  - Appropriate inheritance.
- **Style (20 pts)**:
  - Class names PascalCase.

**Thresholds**:

- **< 50**: Procedural code in a class wrapper.
- **> 80**: True OOP design.

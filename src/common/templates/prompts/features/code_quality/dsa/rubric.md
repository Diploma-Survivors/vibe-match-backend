# Code Quality Rubric (DSA)

Score 0-100.

- **Logic (50 pts)**:
  - Correct edge case handling.
  - No infinite loops.
- **Data Structure Usage (30 pts)**:
  - Correct choice (e.g., using Set for unique items).
  - Efficient usage.
- **Style (20 pts)**:
  - Clean implementation of complex logic.

**Thresholds**:

- **< 50**: Logic fails.
- **> 80**: Optimal and clean.

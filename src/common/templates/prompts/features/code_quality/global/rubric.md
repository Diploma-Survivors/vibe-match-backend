# Code Quality Rubric (Global)

Score 0-100.

- **Readability (40 pts)**:
  - Variables clearly named.
  - Code flow is easy to follow.
- **Maintainability (30 pts)**:
  - No hardcoded magic numbers.
  - Functions are not too long (> 50 lines).
- **Best Practices (30 pts)**:
  - Consistent indentation.
  - Proper resource management (e.g., closing files).

**Thresholds**:

- **< 50**: "Hard to read" or "Spaghetti code".
- **> 80**: "Production-ready" or close to it.

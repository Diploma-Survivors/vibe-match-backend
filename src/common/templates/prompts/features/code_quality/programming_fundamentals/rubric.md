# Code Quality Rubric (Fundamentals)

Score 0-100.

- **Syntax (50 pts)**: No logical syntax errors (e.g., indentation in Python).
- **Flow (30 pts)**: Loops and conditions used correctly.
- **Variables (20 pts)**: Meaningful names.

**Thresholds**:

- **< 50**: Fails to run or confusing logic.
- **> 80**: Clean logic flow.

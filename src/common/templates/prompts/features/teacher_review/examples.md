# Teacher Review Examples

## Example 1 (Good Student)

**Input**:
Perfect submission.

**Output**:
"Sinh viên nắm vững kiến thức. Code sạch, tối ưu. Không có dấu hiệu sao chép."

## Example 2 (Struggling)

**Input**:
Messy logic.

**Output**:
"Sinh viên gặp khó khăn với vòng lặp. Code chạy sai logic cơ bản. Cần hỗ trợ thêm về phần Loop."

## Example 3 (Plagiarism)

**Input**:
Strange variable names or comments in another language.

**Output**:
"CẢNH BÁO: Code có chứa comment tiếng Pháp và style không giống bài trước. Có khả năng copy từ nguồn ngoài."

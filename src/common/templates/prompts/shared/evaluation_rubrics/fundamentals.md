# Evaluation Rubric: Programming Fundamentals

Score student submissions on a scale of 0-100 based on the following criteria.

| Criterion              | Weight | Description                                      |
| :--------------------- | :----- | :----------------------------------------------- |
| **Syntax & Logic**     | 40%    | Code compiles/runs and follows basic logic flow. |
| **Input/Output**       | 30%    | Correctly handles standard input/output formats. |
| **Control Structures** | 20%    | Proper use of loops, conditions, and functions.  |
| **Readability**        | 10%    | Basic indentation and meaningful variable names. |

## Scoring Guide

- **90-100**: flawless execution, perfect syntax.
- **70-89**: functional but has minor logic flaws or formatting issues.
- **50-69**: runs but fails some edge cases; poor formatting.
- **< 50**: syntax errors or completely wrong logic.

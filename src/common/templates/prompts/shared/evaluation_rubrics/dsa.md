# Evaluation Rubric: Data Structures & Algorithms (DSA)

Score student submissions on a scale of 0-100 based on the following criteria.

| Criterion            | Weight | Description                                                              |
| :------------------- | :----- | :----------------------------------------------------------------------- |
| **Correctness**      | 40%    | Does the code pass all logical cases and edge cases?                     |
| **Time Complexity**  | 25%    | Is the algorithm optimal for the constraints? (e.g., $O(n)$ vs $O(n^2)$) |
| **Space Complexity** | 15%    | Is memory usage minimized?                                               |
| **Code Quality**     | 20%    | Naming, readability, modularity.                                         |

## Scoring Guide

- **90-100**: Perfect correctness, optimal complexity, clean code.
- **70-89**: Correct but slightly unoptimized or minor style issues.
- **50-69**: Correct logic but inefficient ($O(n^2)$ where $O(n)$ is needed) or messy code.
- **< 50**: Incorrect logic or fails basic cases.

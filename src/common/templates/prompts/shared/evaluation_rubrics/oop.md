# Evaluation Rubric: Object-Oriented Programming (OOP)

Score student submissions on a scale of 0-100 based on the following criteria.

| Criterion             | Weight | Description                                                 |
| :-------------------- | :----- | :---------------------------------------------------------- |
| **Class Design**      | 30%    | Appropriate attributes and methods; logical encapsulation.  |
| **Inheritance/Poly**  | 25%    | Correct usage of inheritance, interfaces, and polymorphism. |
| **Correctness**       | 25%    | Logic works as intended.                                    |
| **Design Principles** | 20%    | Adherence to SOLID principles (if applicable) and DRY.      |

## Scoring Guide

- **90-100**: Excellent class design, proper use of OOP pillars.
- **70-89**: Good design, minor encapsulation leaks or heavy methods.
- **50-69**: Functional but procedural style disguised as OOP (God classes).
- **< 50**: Misunderstanding of classes/objects.

# formatting/markdown_output.md

## Markdown Output Structure

Ensure your response is beautifully formatted Markdown.

### Rules

1.  **Headings**: Use `##` and `###` to structure sections clearly.
2.  **Lists**: Use bullet points `-` for lists.
3.  **Code Blocks**: Use triple backticks with language identifiers for all code snippets.
    - Example:
      ```python
      print("Hello")
      ```
4.  **Bold/Italic**: Use `**text**` for emphasis and `*text*` for minor highlights.
5.  **Tables**: Use Markdown tables for metrics or comparisons if applicable.
6.  **Math**: Use LaTeX formatting for mathematical complexity if supported (e.g., $O(n)$), otherwise use $O(n)$.

### Structure Template

```markdown
## Tổng Quan (Overview)

[Summary in Vietnamese]

## Chi Tiết Đánh Giá (Detailed Review)

- **Điểm mạnh**: ...
- **Điểm yếu**: ...

## Gợi Ý Cải Thiện (Suggestions)

1.  [Suggestion 1]
2.  [Suggestion 2]

## Code Cải Thiện (Refactored Code)

...
```
